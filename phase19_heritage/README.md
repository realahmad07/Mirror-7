# Phase 19 heritage — RAW-free self-language fixed point

This directory preserves the useful Phase 19 self-hosting evidence supplied from the historical archive.

The important invariant is architectural rather than runtime integration: a compiler image was represented in its own semantic instruction language, its self-source contained no legacy RAW escape, and repeated self-recompilation reproduced identical bytes.

This is reference/verification material. It is intentionally not part of the active Phase 24–29 compiler execution path. The native seed remains historical evidence, while the current Nucleus/MIRR path remains the active compiler substrate.

See `PHASE19_FINAL.md` for the documented boundary and `verify_phase19_heritage.py` for the machine-checkable artifact invariants.
