# Native Brain Research — Experiments 1–7

These seven experiments form the native semantic-state research track recorded during the first Mirror 7 training cycle.

| Experiment | Focus | Outcome |
|---|---|---|
| 1 | Semantic-state learning | Reproducible learned semantic signal. |
| 2 | Transition-focused loss | Stronger transition margin, weaker retrieval. |
| 3 | Explicit operations | Learnable state transformations on a controlled task. |
| 4 | Sequential composition | Revealed representation collapse. |
| 4B | Transformation-specific contrastive loss | Restored compositional discrimination. |
| 5 | Variable-depth chains | Stable but imperfect multi-step generalization. |
| 6 | Opaque learned operations | Exposed a depth/generalization bottleneck. |
| 7 | Residual state transition | Matched Exp6 on length-5 and slightly improved unseen concepts. |

## Why the sequence matters

1. Compact state can be learned.
2. Transition learning can be strengthened independently.
3. Explicit transformations can be learned.
4. Naive sequential composition exposes collapse.
5. A transformation-specific objective improves compositional discrimination.
6. Deeper opaque operations expose a bottleneck.
7. Residual updates help stability without eliminating the bottleneck.

These are bounded research results, not general intelligence scores.
