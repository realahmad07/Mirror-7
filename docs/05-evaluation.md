# Evaluation

## Evidence levels

| Level | Question |
|---|---|
| Unit test | Does a local function behave correctly? |
| Phase acceptance | Does a bounded mechanism satisfy its stated contract? |
| Held-out benchmark | Does behavior transfer to withheld cases? |
| Negative control | Does the mechanism reject cases it should not solve? |
| Multi-seed replication | Does the result survive initialization changes? |
| Independent-style evaluation | Does a fresh evaluator reproduce the bounded result? |
| External evaluation | Can another team reproduce or challenge the claim? |

These levels must not be collapsed into one intelligence score.

## Native-brain results

### Experiment 1

| Metric | Mean | Std |
|---|---:|---:|
| Top-1 | 14.27% | 0.65% |
| Top-5 | 25.47% | 0.69% |
| Semantic margin | 0.2209 | 0.0003 |
| Transition margin | 0.1150 | 0.0048 |

The important evidence is reproducible signal, not high retrieval accuracy.

### Experiment 2

The transition-heavy loss produced:

- transition margin mean: 0.1605;
- Top-1 mean: 0.1293.

The objective improved one target while weakening another. This is recorded as a trade-off rather than a single-metric victory.

### Experiment 4B

Recorded three-seed result:

- compositional margin: 0.2967 mean;
- held-out Top-1: 87.18%;
- order margin: 0.0949.

This is evidence for the defined compositional state benchmark.

### Experiment 5

Variable-length chains:

- mean accuracy: 60.71%;
- standard deviation: 0.0226;
- three validation seeds.

This establishes bounded multi-step behavior, not open-domain reasoning.

### Experiments 6–7

| Model | Length-5 | Unseen concepts |
|---|---:|---:|
| Exp6 baseline | 63.33% | 65.33% |
| Exp7 residual | 63.33% | 65.56% |

Exp7 matched the primary depth result and slightly improved unseen-concept performance. It is not a decisive overall architecture win.

## Language-model evaluation

Teacher forcing supplies the correct previous target bytes.

Free running feeds the model's own generated bytes back into its future context.

The 10M-class route learned enough under teacher forcing to show prompt-conditioned behavior, but free-running continuation remained unstable.

That is why validation loss alone was not accepted as a success criterion.

## Future acceptance rule

A future native language model should be accepted only after it shows:

1. held-out generation quality;
2. repeated-seed stability;
3. prompt-conditioned behavior;
4. free-running robustness;
5. negative controls;
6. leakage audit;
7. improvement over a frozen baseline.

The same benchmark, decoder budget, and evaluator should be preserved when claiming an architecture improvement.

## Historical phase evidence

Older phase reports remain useful and should be read at their stated boundaries. They include bounded evaluations for representation, world-modeling, planning, action, grounding, continual learning, safety, self-improvement, and backend integration.

They are engineering/research evidence, not a replacement for independent external validation.
