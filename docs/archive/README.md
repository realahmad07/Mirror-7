# Historical Archive

The archive preserves material that is useful for provenance but should not dominate the current GitHub UI.

## Legacy workflows

Historical GitHub Actions YAML files moved here are retained as exact source records but are no longer active workflows.

Only files under .github/workflows/ are interpreted by GitHub as active workflow definitions.

## Root reports

The repository still retains historical root-level phase reports in their original locations because moving them blindly could break cross-references and provenance. The new docs pages provide the current navigation layer.

## Preservation rule

Archive means inactive, not deleted.

A historical artifact can remain available for audit without remaining part of the default development path.
